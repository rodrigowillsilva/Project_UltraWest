# Ultra West

A fast, stylish 2.5D FPS roguelite set in the haunted frontier of the Wounded West. Master weapon switching, gun-tied movement, and end-of-night upgrades to survive relentless waves.

## Features

- High-speed arena FPS combat with skill-based weapon swapping
- Each weapon grants a unique movement ability (grapple, dash/air burst, focus time, sprint buff)
- Night-based runs with upgrades between nights
- Low-friction, readable design aimed at smooth performance on modest PCs
