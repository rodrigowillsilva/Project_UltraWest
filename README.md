# Project_UltraWest
Repo for the development of the UltraWest game

## MCP Server for GitHub Access

This project includes an MCP (Model Context Protocol) server implementation for programmatic GitHub repository access. This provides your agent with full control over GitHub operations beyond what GitHub Copilot offers.

### Quick Start

```bash
# Run the MCP server
cd MCPServers
python3 mcpServers.py

# Or run the examples
cd ..
python3 example_mcp_usage.py
```
