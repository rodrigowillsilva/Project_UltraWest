# Roadmap

Milestones to track progress from prototype to release. Dates are indicative and can be refined as the project evolves.
Each milestone has specific goals and deliverables with versions indicated where applicable. Each Milestone has versions (e.g., 0.x, 1.x) to denote sub-phases within the milestone. Each version is going to be separated to have versoned deliverables.

## Prototype

Goal: Prove the core combat loop and gun-tied movement in a single arena.

- Player controller: sprint, jump, basic camera
- Weapon framework: equip/swap, ammo, reload-on-holster
- Two weapons playable (e.g., Revolver and Shotgun)
- Movement abilities for those weapons (sprint buff, grapple)
- Arena test scene (greybox)
- Minimal UI: health, ammo

## Vertical Slice

Goal: Small but polished slice demonstrating intended pace, visuals, and audio.

- Four core weapons implemented with abilities
- First enemy roster (3–5) with distinct counters
- Basic run structure: night start/end, rewards screen
- Readability pass on VFX/SFX and feedback
- Performance sanity on low-end targets
